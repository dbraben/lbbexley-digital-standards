# Compliance documents

- Keep each document true to what the service does now. Update it in the same change, so they're committed together.
- Parts in `{{double braces}}` need real answers from the service team. Don't invent decisions that Information Governance, Communications or the service owner must make: say who needs to decide.
- No personal data, and no names of residents. Name teams and roles.
- `npm run check:release` must pass before go-live.
