# Getting help

- **Getting started:** [docs/onboarding.md](docs/onboarding.md) takes a developer from nothing to a first finished story.
- **How the harness works:** the README's tables, and the skills themselves in `plugins/lbbexley/skills/`.
- **A finding you think is wrong:** open a "Standards check false alarm" issue. Meanwhile, suppress it on that line with a written reason.
- **An idea for the standards:** run `/lbbexley:improve` in your app repository, or open a "Harness improvement" issue.
- **Anything else:** ask the Digital Team in their Teams channel.

For Microsoft's platform documentation, ask the assistant: the Microsoft Learn MCP server is set up in the plugin.
