# Brand assets

The approved London Borough of Bexley logotype files:

- `bexley-logo.png` (423 by 139 pixels): for canvas apps and emails. In a canvas app, add it to the app's media and set the header image's `Image` property to it. It's sharp at the header's 160 by 48 and anything up to twice that.
- `bexley-logo.svg`: preferred for web and Power Pages, once Communications supplies it. Until then, use the PNG.

Rules for every use:

- Alt text: "London Borough of Bexley". When the logo links to a home page, the alt text says where it goes, for example "London Borough of Bexley – home".
- Don't redraw, recolour, stretch, crop or rotate the logo, or place it on a busy background or image.
- Keep clear space around it as Communications specifies.

Never draw or rebuild the logo in code, CSS or SVG: always use these files.
