# Emails, Word documents and PDFs

## HTML first

Publish information as a web page wherever possible. It's the best way to reach the most people, and it works with mobiles and screen readers. If a document is needed as well, it's an extra, not the only version.

## Emails sent by flows

- Real text, never images of text. Text black on white, Lato then Arial.
- A clear subject line that names the service, for example "Bexley parking permit: application received".
- Use headings and lists in the HTML so screen readers can navigate.
- Link text says where it goes; no "click here".
- Logo image with alt text "London Borough of Bexley".
- Show a reference number and what happens next. Say how to contact the service.
- No tracking pixels.
- No personal data beyond what the recipient needs, and nothing sensitive in the subject line.

## Word documents (including templates that flows fill in)

These rules come from the council's Word and PDF guide on B:HIVE:

- Start from a council template: Custom templates in Word (Aqua, Black, Fuchsia, Royal and Spring), which have the right branding and heading styles.
- Use the built-in Heading styles: one Heading 1, then Heading 2 for sections, Heading 3 inside those. Check the structure in View > Navigation Pane.
- Use the built-in bullet and numbering buttons for lists.
- Alt text on every image (right-click > Edit Alt Text); tick "Mark as decorative" for decoration. No screenshots of text: if you can't select it, it isn't real text.
- Tables: tick Header Row in Table Design and set Repeat Header Rows. If a row or column changes meaning partway through, split it into two tables.
- Charts: alt text with the key message, and the data in an appendix table.
- No text boxes; use a bordered paragraph instead.
- File > Info > Properties: give the document a meaningful Title. Set the proofing language.
- Run Review > Check Accessibility and fix what it finds.

## PDFs

- Create them from an accessible Word document and save as PDF/A.
- Check with Adobe Reader (Edit > Accessibility > Quick check). Fix problems in the Word source, or in Acrobat Pro.
- For old PDFs already online, follow the decision flowchart in B:HIVE's "What you should do with PDFs already online" guide.

## Spreadsheets and CSV files

Run the Office accessibility checker, name the sheets, use one header row, and don't merge cells.
