# Words and patterns

## Words to avoid

| Instead of | Write |
|---|---|
| utilise | use |
| commence | start |
| facilitate | help, make possible |
| in close proximity to | near |
| in order to | to |
| prior to | before |
| in the event of | if |
| at this point in time | now |
| a number of | some, or the actual number |
| assistance | help |
| purchase | buy |
| require | need |
| ensure | make sure |
| additional | more, extra |
| individuals | people |
| advise | tell |
| submit (in body text) | send |
| deliver (for services or policies) | provide, run, give |
| key (unless it unlocks something) | important, main |
| robust | strong, or say what it is |
| streamline | simplify, speed up |
| leverage | use |
| empower | let, allow |
| going forward | from now on, or delete |
| seamless | say what's actually easy |
| tackle, combat, drive (for policy) | say what you're doing: reduce, stop, improve |
| one-stop shop | say what people can do there |

Never use "Oops", "Uh-oh", "Whoops" or jokes in messages about problems.

## Buttons

- Say what happens, starting with a verb: "Send request", "Book appointment", "Save and continue".
- Use "Continue" between steps of a form and "Submit" or "Send" only on the last step.
- A button that starts a service: "Start now".
- Never "OK", "Go", "Click here" or "Yes" alone where the action isn't obvious.

## Labels and hints

- Labels name the thing: "Postcode", "Date of birth", "Email address".
- Questions as labels work well one per page: "What is your postcode?".
- Hints explain format or why we ask: "For example, 27 3 2007", "We'll only use this to contact you about your request".
- Mark optional fields with "(optional)". Don't use asterisks for required fields.

## Error messages

Say what's wrong and how to fix it, in plain words. Use the same wording in the error summary and next to the field.

| Problem | Message |
|---|---|
| Required text field is empty | Enter your full name |
| Required choice not made | Select how you want to be contacted |
| Checkboxes, none ticked | Select all the services you need |
| Too long | Description must be 500 characters or less |
| Too short | Reference number must be 8 characters |
| Number out of range | Number of bags must be between 1 and 6 |
| Email in the wrong format | Enter an email address in the correct format, like name@example.com |
| Phone in the wrong format | Enter a telephone number, like 01632 960 001 or 07700 900 982 |
| Postcode in the wrong format | Enter a full UK postcode, like DA6 7AT |
| Date missing a part | Date of birth must include a month |
| Date not real | Date of birth must be a real date |
| Date must be past | Date of birth must be in the past |
| Date must be future | Appointment date must be in the future |
| File wrong type | The selected file must be a JPG, PNG or PDF |
| File too large | The selected file must be smaller than 10MB |
| Something went wrong on our side | Sorry, there is a problem with the service. Try again later. Your answers have not been saved. |

Rules:

- No "please" and no "sorry" in field errors. "Sorry" is only for problems the council caused.
- Don't blame the user ("you forgot", "you failed to").
- Avoid "invalid", "illegal", "forbidden", "valid" and technical codes ("Error 400").
- No exclamation marks, and no colour-only signals.

## Confirmation pages and messages

- Heading that says what happened: "Request sent", "Appointment booked".
- The reference number, prominent: "Your reference number is BX-104233".
- "What happens next", with timescales: "We'll contact you within 5 working days."
- How to get help, and how to change or cancel if that's possible.
- Brand: a confirmation panel uses BexleySpring with white text.

## Emails sent by flows

- Subject: service name and what happened, for example "Bexley parking permit: application received". No personal details in the subject.
- First line: the key fact. "We've received your parking permit application, and we'll decide by Tuesday 2 March 2027."
- Then: reference number, what happens next, how to contact the service.
- Sign off as the service, for example "Parking Services, London Borough of Bexley".
- Don't send from a personal mailbox. Use the service's shared mailbox.

## Empty, loading and "nothing found" states

- Say what's missing and what the person can do: "No requests yet. Requests you make will appear here."
- Search with no results: "No results for 'skip hire'. Check the spelling or try a different word."
- Loading: say what's happening if it takes more than a second or two: "Finding addresses".

## Alt text

Describe the meaning, not the picture. Ask: "What would I say about this image if I read the page to someone on the phone?" Skip "image of" and "picture of". Decorative images get empty alt text.
